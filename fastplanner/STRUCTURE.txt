Getting Started
===============

1. Quick Start (Automated):
   ./scripts/quick_start.sh

2. Using Make:
   make          # Build everything
   make test     # Run tests
   make examples # Run demos

3. Manual CMake:
   mkdir build && cd build
   cmake -DCMAKE_BUILD_TYPE=Release ..
   make -j$(nproc)
   ctest
